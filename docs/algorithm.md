# 算路口径与算法边界

选型引擎 `js/engine.js` 怎么算、为什么这么算，以及它做不到什么。页面上的「验算过程」逐项复现同样的公式与数字，可以自己拿计算器核对；也可以到工程计算器 `calc.html` 把 17 个公式按 6 个场景组合复算（口径由 `js/calc.test.js` 保证一致）。

## 输入项

| 输入 | 含义 | 影响 |
|---|---|---|
| 视野 FOV 宽 / 高 | 要拍到的范围 mm | 决定所需像素数、所需焦距 |
| 最小特征 δ | 要分辨的最小缺陷/公差 mm | 决定像素精度 |
| 检测任务 | 测量 / 缺陷 / 有无 / OCR / 颜色… | 决定"每个特征占几个像素"和光源方式 |
| 工作距离 WD | 镜头前端到工件 mm | 与焦距、视场互相约束 |
| 被测物材质 | 金属高光 / 哑光 / 塑料 / 玻璃… | 决定光源类型与颜色 |
| 目标主色 | 被测特征的颜色 | 决定单色光波长 |
| 需要彩色相机 | 颜色区分或真实还原 | 黑白/彩色；彩色所需分辨率 ×1.2（Bayer 余量），链路位深按单通道 8bit |
| 工件高度变化 | 沿光轴的起伏 mm | 决定所需景深与光圈 |
| 运动速度 / 节拍 | mm/s、件/分 | 决定曝光上限、帧率、接口 |
| 优先线扫方案 | 勾选 | 面阵可行时也一并给出线阵建议（超长幅面 / 高速连续检测） |

## 算路口径（可复核）

**1. 像素精度**

```
像素精度 = δ / k
k = 每个最小特征需要占用的像素数
```

| 任务 | k | 理由 |
|---|---|---|
| 精密尺寸测量 | 5 | 亚像素边缘拟合，要求最严 |
| 一般测量 / 定位 / OCR | 4 | 边缘定位需要几个像素 |
| 缺陷检测 / 表面质量 | 3 | 能把缺陷和噪声分开 |
| 有无 / 装配确认 | 2.5 | 只判存在性 |
| 颜色区分 | 2 | 大面积颜色，不需要高分辨率 |

**2. 所需分辨率**

```
H_px ≥ 视野宽 / 像素精度
V_px ≥ 视野高 / 像素精度
```

在相机表里**从小到大**取第一台两个方向都满足的（够用就好，不浪费）。

**3. 焦距**

```
所需放大倍率 m₀ = 靶面高 / 视野高
所需焦距 f = WD · m₀ / (1 + m₀)
```

取**不大于**该值的最大标准焦距（6/8/12/16/20/25/35/50/75/100mm），
这样实际视场只会变大不会裁掉工件。再反算：

```
实际放大倍率 m = f / (WD − f)
实际视场 = 靶面 / m
有效像素精度 = 实际视场 / 像素数   ← 必须仍 ≤ δ/k，否则升一档相机
```

**4. 景深**

```
DOF = 2 · F · c · (1 + m) / m²      c = 2 像元
```

从小到大试 F4 / 5.6 / 8 / 11 / 16，取第一个满足「工件高度变化」的；
同时检查衍射：艾里斑直径 2.44·λ·F，若换算到像面 > 2.5 像素就提示。

**5. 曝光 / 帧率 / 带宽**

```
曝光上限 = 像素精度 / 运动速度      （保证运动模糊 ≤ 1 像素）
帧率     = 速度 / 实际视场高 × 1.2  （静态拍摄默认 15fps）
带宽     = H × V × 位深 × 帧率 / 8
有效带宽 = 接口理论线速 × 0.85      （扣包头 / 协议 / 帧间隔开销）
```

位深取相机**单通道原始输出**的 8 / 10 / 12 bit（型录逐型号给 `bitDepth` 时优先用），
黑白与彩色 Bayer 都是单通道，RGB 插值发生在上位机、不占相机→采集端链路，因此彩色不再按 16bit 估算。
有效带宽参考值（MB/s）：GigE 93.5 / 2.5GigE 238 / USB3 297.5 / 5GigE 476 / 10GigE 935 /
CameraLink 578 / CoaXPress 1062.5 / GMSL2·BCON 340。选优阶段**先按有效带宽淘汰放不下的接口**。

**6. 光源**

按「任务 + 材质」查规则表：

| 情况 | 照明方式 |
|---|---|
| 测量轮廓 / 玻璃透明件 | 平行背光（精密测量用远心背光） |
| 金属高光面 + 缺陷/划痕 | 低角度条形光（暗场）+ 偏振 |
| 镜面 / 曲面（非缺陷任务） | 圆顶（球积分）无影光 |
| 字符 / 条码 | 同轴光 |
| 有无 / 定位 | 高角度环形光 |
| 一般表面缺陷 | 低角度条形光 |

颜色按「同色提亮、补色压暗」：

| 目标色 | 推荐光 | 互补（压暗用） |
|---|---|---|
| 黄 / 铜 / 金 | 黄光 590nm | 蓝光 450nm |
| 红 | 红光 625nm | 青光 490nm |
| 绿 | 绿光 525nm | 红光 625nm |
| 蓝 | 蓝光 450nm | 黄光 590nm |
| 黑 / 深色 | 红外 850nm | 白光 |
| 未指定 + 金属高光 | 蓝光 450nm（抑制镜面成分） | — |
| 未指定 + 其它 | 红光 625nm（通用、消色差） | — |

曝光 < 1ms 或速度 > 300mm/s 时自动改推**频闪控制器**。

### 精度预算（实际可达精度）

理论像素精度只是"一个像素多大"，页面下方会再算一层工程误差，按均方根合成：

| 误差项 | 估算方式 |
|---|---|
| 像素量化 | 1 像素对应的实际尺寸 |
| 亚像素定位 | 0.3 像素（边缘/质心算法） |
| 镜头畸变残差 | 畸变规格（%）× 视野 / 2 × 20%（标定后残差） |
| 标定与装夹 | 0.5 像素 |

合成值若超过"要求的像素精度 δ/k"，风险区会提示提高分辨率或加强标定。

### 安装空间

```
需要的总长 = 工作距离 WD + 镜头长度 + 相机厚度 + 线缆余量 25mm
```

- 相机厚度取自官网**外形尺寸**（192/300 型号有）；缺数据的按 45mm 估并标注
- 镜头长度：**75/85 支取自手册外形尺寸图**（HF-E / HF-P / MF-E / MF / MF-10MPE / MF-8MPS / KF / KF-E / KF-P / KF-P 抗振 / AF / M12），
  其余 10 支 LF 系列按系列典型值估算；界面标注"手册图"还是"估算"。
  图纸是位图 + 双栏排版，需逐张核对图号归属（数据在 `tools/lens-lengths.json`，可续填；`tools/extract-lens-lengths.py` 是半自动抽取脚本）
- 填了「可用安装空间」且超长时，风险区会给出超出多少毫米

### 现场参数建议

不建照度模型，只给"可照抄的起始值"，最终以现场直方图与标准件为准：

| 项 | 给什么 | 怎么算 |
|---|---|---|
| 光圈 | 当前档位 | 已在景深允许的最大光圈；下一档按 `2·F·c·(1+m)/m²` 重算景深，衍射 `2.44·λ·F/像元` ≤ 3 px 才建议收（说明栏给出下一档的景深与衍射） |
| 曝光 | 起始值 + 上限 | 运动：上限 = 像素精度 / 速度 × 1000 ms；静态：先按 2 ms 试拍，钳在相机 `expMin~expMax` 内 |
| 增益 | 0 dB | 优先用照度与曝光把灰度做到 70–80%，增益只在不足时小幅加（≤ 6 dB） |
| 触发 | 软触发 / 硬触发 + 频率 | 有速度或节拍 → 硬触发（光电 / 编码器），频率取方案帧率 |
| 调光 | 控制器 + 通道 + 频闪 | 曝光 < 1 ms 或速度 > 300 mm/s → 要求频闪控制器，脉冲宽度 = 曝光时间 |

### 安装与配套 / 验收

- 安装配套 = 尺寸链（WD + 镜头 + 相机 + 线缆 + 支架 40 + 调整余量 10）+ 接口对应线缆 + 6-pin 触发线 +
  镜头附件（转接环 / 滤镜螺纹需按实物口径确认）+ 光源支架与控制器 + 供电功率（按 1.5 倍预留）。
- 验收清单固定五项：重复性 0.3 像素（3σ）、测量偏差 0.5 像素、图像对比度 ≥ 30（建议 ≥ 60）、节拍、环境（±5 ℃ / 遮光 / 减振）；
  并按当前方案追加重点项（余量 < 15%、预算占比 > 80%、曝光 < 1 ms、衍射逼近上限、空间不足）。

### 选型依据（与次优对比）

把首选与**次优整机方案**按同一套口径（与匹配度分数相同的 `scoreOf`）逐项对比：
匹配度、相机像素数、像素精度、精度余量、接口 / 带宽、镜头是否需转接。
差异超过容差（分辨率 2%、像素精度 0.5%、余量 1 个百分点）才判"占优 / 让步"，否则记"持平"；
全项持平时提示"可互换型号，按供货与价格二选一"。手动指定型号不参与对比。

## 评分与选优口径

`scoreOf(metrics)` 是**唯一**的评分规则：页面展示（`solve`）、自定义搭配（`evaluateCombo`）、
选优排序、备选方案对比四处都调用它；候选指标由 `metricsFromCand()` 统一构造，一律用该候选的
**实际视场**算帧率与带宽，不再出现「按 A 尺子选、按 B 尺子显示」。

扣分不是阈值开关，而是按越界程度连续给分：

```
扣分 = round(权重 × min(1, 越界量 / 跨度))
```

| 项 | 起始阈值 | 满额权重 | 跨度 |
|---|---|---|---|
| 精度余量不足 | 余量 < 15% | 12 | 15 个百分点 |
| 景深不足 | 景深 < 高度变化 | 15 | 缺口达高度变化的 50% |
| 衍射限制 | 弥散 > 3 px | 8 | 再超 2.5 px |
| 曝光短于相机下限 | 允许的最长曝光 < `expMinUs` | 8 | 缺口占 `expMinUs` 的 100%（上限压到 0） |
| 焦距档位偏离 | > 15% | 8 | 再偏 35 个百分点 |
| 视场过剩 | > 20% | 6 | 再超 50 个百分点 |
| 帧率不足 | > 相机 `maxFps` | 10 | 超出量达 `maxFps` |
| 带宽超限 | > 有效带宽 | 10 | 超出量达有效带宽 |
| 需转接环 | — | 3（固定） | — |
| 硬性条件不满足 | `feasible=false` | 45（固定） | — |

总分 `max(5, 100 − 各项扣分)`。连续化后余量 14.9% 与 15.1% 只差 0~1 分，参数微调不会让推荐型号来回跳。

页面顶部的「N / 9 项核查通过」取自同一套 `checks`：硬性条件、精度余量、景深、衍射、曝光上限、焦距档位、视场利用、帧率、带宽共 9 项（转接环只在用到时追加扣分，不计入这 9 项）。粗略的「1 ms 曝光门槛」已不再扣分——高速场景的上限本就低于 1 ms，硬卡会把可交付方案全判失败；真正卡人的「短于该相机最短曝光」仍按上表扣分。衍射阈值取 **3 px**（`DIFF_LIMIT_PX`），与评分和验算表口径一致。

**硬约束否决**：帧率跑不到、链路带宽不够、曝光短于相机最短曝光、安装空间放不下、精度预算超差，
选优时先从达标方案中淘汰；只有一台都过不了时才退回软扣分，并在页面保留警告。
手动指定的型号不参与淘汰，但评分与风险区仍如实显示问题。

另外两处口径：

- 彩色 Bayer 插值后细节分辨率低于同像素黑白机，所需分辨率乘 **1.2** 再筛相机；
- 镜头解析力需求按 Nyquist 随像元尺寸调档：`camMp × 0.85 × clamp(3.45/pxUm, 0.85, 1.35)`，
  同样 12MP 的小像元相机要求更高，不再只比 MP 数字。

## 这套算法的边界

- 主搜索只在**面阵相机 × FA/M12 镜头**里进行。线扫与远心走独立通道：
  - **线扫**给出完整方案：相机型号 + 所需倍率/焦距/像面宽 + 行频需求 + 线光源型号 + 带宽校验；
    但线扫镜头需按像面宽度另选（手册未收录线扫镜头）。
  - **线扫多机拼接**只在勾选「优先线扫方案」后计算：单台线扫覆盖不了整幅时，按重叠率（默认 10%，可调）与台数上限（默认 6，可调）
    逐档算 2~N 台的单台视场、光轴间距、重叠像素、精度与合计带宽，给俯视排布图；不勾线扫、或单台就够时都不提示。
    拼接需要现场做同步触发、跨台标定与亮度一致性，工具只给排布与参数，不替代现场调试。
  - **远心**给出系列 + 倍率，并**校验工作距离是否落在该系列 WD 区间内**；
    景深按 F8 估算（远心实际工作光圈以型号为准），超出范围会明确标为不可行。
- 板级相机中裸板式（无镜头接口，型号后缀 `-B`）会被自动排除；`-C` / `-S` 分别按 C 口 / M12 配镜。
- 镜头**最近摄距**参与筛选：工作距离小于最近摄距的镜头会被剔除，接近时给警告。
- 大恒镜头/远心的**像面直径、靶面、光圈档位、最近摄距**按手册同型号行窗口补录（像面覆盖 544/578、最近摄距 576/578）；
  手册同一格印了两个值、或视场角反算与印刷焦距偏差超 8% 的型号一律不入库，宁缺毋滥，逐条证据见 `tools/_cache/_daheng_probe_md.txt`。
  线阵大像面（BV-L / HN-P 16K）与电动调焦（ELM）按 `lensKind` 标注，与普通定焦**不互为同规格可替换**。
- **固定光圈**镜头（手册光圈列只印一档，如大恒 M\*-MPW2-R / RV·FV·MV、海康 MVL-KF·MVL-HF，共 170 支）：详情页显示 `F2.4（固定光圈）`，
  选型时光圈上限取它自己那一档（不再按可收到 F22 计算景深），且不与可调光圈镜头互标同规格。
- 光源按 **类型 + 颜色 + 尺寸 + 功率** 在六品牌合并后的在售光源池（清洗后 4066 款）中选型，并自动匹配控制器型号（同品牌优先、按通道数）；
  池子先由 `js/selection-catalog.js` 剔除退市与必要参数缺失的条目，线阵 / 远心走各自的建议路径，不混进面阵 + 定焦的主算路；
  但**照度**仍需现场试样——工具算不出工件反射率和环境光。
- 相机详细参数（动态范围/信噪比/曝光/PoE）覆盖官网在售型号（187/300），旧型号显示为 `—`；
  短曝光 + 低信噪比会主动告警。
- 光源颜色标准系列只有白 / 红 / 蓝 / 红外；绿、黄、青光会退回白光并提示需定制。
- 焦距只能取库里已有的档位，所以有时「视场略大于需求」（像素被摊薄几个百分点），界面会提示。
- 景深用几何光学近似，不含镜头像差；微距（m > 0.3）场景误差会变大。
- 价格、货期、停产状态未入库，最终选型仍需与供应商确认。
- 评分权重是一组固定经验值，暂未提供「精度优先 / 速度优先 / 成本优先」的权重切换。
- 工程计算器 `calc.html` 只做公式计算：不查型号库、不预填参数、不生成方案，也不替你判断型号能否买到；照度与现场试样的边界同上。
