# 使用说明

五个页面顶部有同一组导航，从主页点进去即可，也可以直接打开对应的 HTML 文件（无需本地服务）。

## 两种阅读深度：简明 / 专业

选型助手右上角有「简明 / 专业」两档，同一份计算结果，换两种说法。选择记在浏览器本地，下次打开还是上次那档；
网址加 `?mode=pro` 可直接进专业模式，加 `?mode=simple` 强制回到简明。

| | 简明（默认） | 专业 |
|---|---|---|
| 给谁看 | 产线、采购、第一次接触视觉的人 | 相机 / 镜头 / 光源的选型与调试工程师 |
| 左栏需求 | 只留 3 项：视野、检测任务、被测物材质。**最小特征与工作距离不出现**（按 0.1 mm 缺陷、300 mm 工作距离估价，结论下方会写明这两个假设值）；目标主色、高度变化、运动速度、节拍、安装空间、彩色、线扫与拼接参数收进「专业参数」折叠条，点它会直接切到专业模式 | 全部字段摊开 |
| 品牌范围 | 常驻，三行品牌标识可点选排除 / 纳入 | 同上 |
| 右栏 | 一整块深色结论板：一句人话结论（放大到 30 px 上下）+ **光路示意**（相机 → 镜头 → 视野锥 → 工件面，标出视野与 WD）+ **三格成绩单**（精度 / 景深 / 安装，数字 29 px，附要求值）+ 三件套（编号、品牌标识、型号、一句用途、关键规格，整卡可点进产品库）+ 导出 PDF / 复制链接 / 复制方案 | 9 / 9 工程核查进度、三件套速览、9 项核查 chip、详细方案（三件套完整参数、线扫拼接、同系列、风险、BOM、验算、工程细节） |
| 详细方案 | 不显示；假设条右侧的「调整这两项」与顶栏「专业」都能切过去 | ≥ 1021 px 默认展开 |

「评分明细」（每项扣多少分）与「次优方案逐项对比」两块已下线：结论卡仍保留 9 项核查的通过状态，匹配度分数只在备选方案之间比较时使用；要看次优机型直接到「同系列参数」里点选。

## 从需求到方案

1. 双击 `home.html`（Chrome / Edge 均可），从主页进入选型助手，或直接双击 `index.html`。
2. 左栏「检测需求」是常驻面板，填完右侧结果实时刷新（输入 120 ms 防抖，下拉 / 勾选立即重算）；
   其中「可用安装空间」填 0 表示不校验，填了就会检查 WD + 镜头 + 相机 + 线缆是否放得下。
   窄屏时左栏解除固定高度、改为随页滚动，滚到底仍能看到全部字段。
   简明模式只露视野、检测任务、被测物材质三项，最小特征与工作距离按默认值算并在结论下方标明，
   其余参数在「专业参数」折叠条里（点它会切到专业模式，折叠条同时摊开）。
3. 顶栏「快速试用」有 6 个预设场景（铜线检测 / 精密测量 / 二维码读取 / 表面划痕 / 高速在线 / 玻璃件），点一下就有结果。
4. 左栏「同系列参数」列出**该系列全部型号**（相机按像素、镜头按焦距、光源按尺寸），
   每个列表在框内滚动、表头吸顶，并自动滚到当前方案所在行；
   相机块与镜头块下方各有一个「**跨品牌等价替换**」子表（相机比同分辨率/接口/彩色，镜头比同卡口/焦距），
   与右侧方案并排——**点任意型号即可手动指定**，方案会立刻变，不用上下滚动对照；
   再点一次取消，或用「恢复自动选型」回到自动结果。
   除最优方案外，引擎还会给出最多 3 套**备选方案**（另一台可行相机 + 其匹配镜头）；
   属于备选方案的机型，在「够用?」列（相机）或型号列（镜头 / 光源）会标一个「备选」小标签，便于横向比较、点选切换。
   镜头与光源还会各自再列 **最多 3 个更直接的备选**：同一台相机下另一支仍满足精度的镜头（可能是别家品牌或经转接环）、
   同一照明方式下尺寸同样够用的另一款灯具（其他品牌优先、超配不超过 2.5 倍），这些也都标在面板里，点选即切换。
5. 结论卡首屏是三项关键判定：**精度**（有效像素精度 / 需求）、**景深**（覆盖高低差）、**安装**（按总长预留空间），
   简明模式下压成「三格成绩单」，数字最大、判定状态用彩色圆点标出（青=通过 / 琥珀=偏紧 / 红=不足）。
   「导出 PDF」在纸面上会把深色结论板换成白底深字，光路图换深色线条，适合直接打印或转 PDF 给非技术同事看。
   专业模式下分数下面是 9 项工程核查（硬性条件 / 精度余量 / 景深 / 衍射 / 曝光上限 / 焦距档位 / 视场利用 / 帧率 / 带宽）的通过状态，
   悬停可看每项的实际数值；逐格推导在「验算过程」里。
6. 方案下方「**现场参数建议**」给出上机可照抄的起始值：光圈档位（可否再收一档）、曝光起始值与上限、增益 0 dB 策略、
   软/硬触发与频率、调光与频闪要求；右侧「**安装与配套清单**」把尺寸链、数据线、触发线、镜头附件、光源支架、控制器、供电一次列全。
7. 页面下方「验算过程」与「风险与建议」并排在同一行，一边看算式一边看风险；最底部「**验收与复核清单**」列出重复性、
   测量偏差、图像对比度、节拍、环境五项的验收指标与测法，并按当前方案给出重点复核项。
8. 「复制方案文本」可整段复制到微信/邮件/报告里（含以上四块新内容；手机上改成底部抽屉展示，长按可选中复制）；
   「复制链接」把当前需求与已固定的型号编码进网址，对方打开即还原同一份结果，适合发给同事复核。
   方案区下方「方案清单（BOM）」可逐项或整单加入**询价清单**，「导出 PDF」走浏览器打印。
9. 看到常用的型号，点列表行首（手机为型号旁）的 **☆** 收藏，或在详情弹层点「☆ 收藏」；顶部「★ 收藏」标签只列收藏。
   收藏的相机 / 镜头 / 光源会出现在搭配页三个选择器里——不输入关键词时直接列出收藏，点一下即填入。
10. 超长幅面 / 高速连续检测：勾选左栏「**优先线扫方案**」后才会出现「拼接重叠率」（默认 10%）与「拼接台数上限」（默认 6 台）。
    单台线扫覆盖不了整幅时，详细方案里会多出「线扫多机拼接」卡：2~N 台沿幅面并排、算单台视场 / 光轴间距 / 重叠像素，
    逐档对比台数 / 相机 / 镜头 / 行频 / 合计带宽，并附俯视排布图与同步、标定、亮度、链路四条现场要求。
    不勾选时拼接卡与两个参数都不出现（单台就够时也不提示）。
11. 想自己搭配：点顶栏「自定义搭配」（或产品库详情里的「加入搭配」）进入 `combo.html`，
   先在「检测需求」填同样的参数，再从三个可搜索的下拉框里挑相机 / 镜头 / 光源——
   系统按与自动选型完全相同的公式逐项判定，列出「要求 / 实际 / 结论」，并针对不达标项给出替换型号；
   满意后点「应用到选型助手」把需求与手动选型带回 `index.html`。

## 产品库速查

- 页签固定 11 类（面阵 / 线阵 / 镜头 / 远心 / 光源 / 控制器 / 3D / 工控机 / 红外 + 收藏 + 全部），选中态是青色胶囊；搜型号 / 传感器关键词会跨页签自动切到命中的类别。
- 多型号对比表可「导出 CSV」（带 BOM，Excel 直接识别 UTF-8）；参数卡里的「同系列」可一键跳到选型助手按该系列查。
- 收藏与询价清单在页签里单独成页，194 款退市型号可查但不参与选型推荐。

## 带参数直接打开预设

方便把某个场景直接发给别人看：

```
index.html?p=copper     铜线检测
index.html?p=precision  精密测量
index.html?p=qr         二维码读取
index.html?p=scratch    表面划痕
index.html?p=inline     高速在线
index.html?p=glass      玻璃件
```

## 工程计算器：按场景一次算全

`calc.html` 不生成方案，只把方案里常算的公式做成 **6 个组合计算器**。打开时**所有输入为空、不预填任何示例值**；同一个条件在一组里只填一次，组里「输入齐了」的公式立刻一起出结果，不用为了某一式把整套条件重填一遍。
页面顶部是模块概览（6 组 / 17 式 / 已算出结果数）与模块索引，索引带状态点（未填 / 部分完成 / 全部算出）并随滚动高亮，窄屏改为横向滑动不换行；模块卡带编号与状态边，结果以主数值突出、单位用灰色小字，公式步骤压成「名称 + 公式 + 数值」两行。

| 组合 | 输入 | 一次算出 |
|---|---|---|
| 面阵成像与精度 | 最小特征、任务、视野、靶面、相机像素、WD（畸变、安装深度可选） | 像素精度、所需分辨率、放大倍率、焦距档位、实际视场、有效像素精度、精度预算、WD 反算 |
| 运动、曝光与帧率 | 速度、光圈、像元、倍率与精度（自动带入）、最短曝光与 Δh（可选） | 曝光上限、需求帧率、景深与衍射 |
| 接口与安装 | 相机像素、位深、帧率（自动带入）、接口、WD、镜头长、相机厚 | 带宽与接口校核、安装空间尺寸链 |
| 线扫行频 | 速度、最小特征、任务、线阵像素、像元、标称行频（可选） | 行频、含余量行频、像面宽 |
| 远心倍率 | 视野、靶面、WD、系列 WD 区间（可选） | 所需倍率、设计视场、WD 校核 |
| 照明与单位速查 | 任务、材质、目标主色（可选）、数值与单位 | 照明方式与光色、单位互换 |

几个交互规则：

- **算不出的不报错**：结果卡变成「待填」，直接写清缺哪一项（如「需先算『实际视场』，还缺工作距离 WD」），点「去填」跳到那个输入框并高亮。
- **自动带入标来源**：组内推导出来的量（建议焦距、实际视场、有效像素精度、放大倍率、需求帧率）自动填进输入框，输入框下方标「自动 · 来自 XX」，随时可以改，改后以你填的为准。
- **组内共享、组间继承**：同一组的条件只填一次；上一组算出来的量带到下一组，用户填的原始条件各组独立，不同方案不会互相污染。
- **复制**：每个结果可单独复制（公式 / 代入 / 结果 / 结论），也可「复制本组结果」整段贴进方案文档；「清空本组」只清这一组，顶部「清空全部」重置整页。

口径与选型助手 `js/engine.js` 完全一致（k 表、光圈档、焦距档、接口有效带宽 × 0.85、λ = 0.55 µm、彩色 Bayer × 1.2），由 `js/calc.test.js` 逐式与逐组回归（41 项）；页面不读写型号库，也不联网。
